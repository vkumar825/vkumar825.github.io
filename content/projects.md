A selection of personal projects that I've built.

---

## [DCF Calculator](https://vkumar-dcf.streamlit.app/)

Interactive corporate valuation engine built with Python and Streamlit. It ingests SEC 10-K filings via EDGAR to calculate WACC, project unlevered cash flows, and estimate intrinsic share prices.

---

## [arXiv Search](https://github.com/vkumar825/arxiv-search)

Hybrid academic search engine combining full-text keyword matching and Milvus vector search, built with Node.js, Express, and React.

---

## [Porchfest Mobile App](https://github.com/vkumar825/porchfest-pro)

Cross-platform mobile app built with React Native and Expo for Ithaca Porchfest attendees, featuring performer discovery, personalized schedules, and interactive festival maps.

---

## [Contact Book](https://github.com/vkumar825/contact-book)

Desktop contact management app built with Python, Tkinter, and MongoDB, implementing a custom Trie data structure for fast prefix-based search.
