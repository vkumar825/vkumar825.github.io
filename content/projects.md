## arXiv Search

A semantic search engine powered by Milvus, Node, Express, and React for finding arXiv papers via hybrid search.

I got interested in this project when I discovered the arXiv dataset on [Kaggle](https://www.kaggle.com/datasets/Cornell-University/arxiv) and thought it would be interesting to use it with the Milvus vector database.

- **Stack:** Node.js, Express.js, React, Python, Milvus
- **Features:** Keyword + semantic search, efficient filtering, robust backend, and clean interface.
- **Links:** [GitHub Repository](https://github.com/vkumar825/arxiv-search)

## Porchfest Mobile App

A group project we did for the Mobile Development class in 2022 to create a mobile app to assist first-time and returning Ithaca Porchfest attendees.

I led the team and helped coordinate a plan to turn our proof of concept into a working mobile app by sticking to it as much as we could, checking things off as we went, and developing iteratively.

- **Stack:** React Native, JavaScript, Expo
- **Features:** Search and favorite performers, viewable schedule, and an interactive map
- **Links:** [GitHub Repository](https://github.com/vkumar825/porchfest-pro)

## Contact Book

A project I started right after I graduated from college back in December 2022.

The idea for this project came to my mind when I read about an interesting data structure called a **Trie**, and saw one of the use cases was a contact book application.

- **Stack:** Python, Pymongo, Tkinter, MongoDB
- **Features:** Login/Register system, Trie-based search, functioning GUI application, NoSQL database system
- **Links:** [GitHub Repository](https://github.com/vkumar825/contact-book)
